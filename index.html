Auto-publish to GitHub

When on, every change you make is committed to sites.json in your repository, and the live site updates a minute or two later. Create a fine-grained personal access token limited to this one repository with Contents: Read and write (GitHub → Settings → Developer settings → Fine-grained tokens). The token is kept only for this browser tab: it is forgotten when you close the tab or log out, so you will paste it again next time. It is never included in exports or backups.
